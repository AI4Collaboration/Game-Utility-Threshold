Separate code, native Inspect and source

These are versioned copies of the PD and Stag Hunt structures. They do not change the base games or their collectors. The finite private-reward setup follows Harsanyi's incomplete-information model; the payoff profiles and cost intervention are our adaptation.

Run python private_games.py run runs/private-check --game all --figures after pip install '.[inspect,figures]'. View traces with inspect view --log-dir runs/private-check/logs. This command uses mock models only. It saves native logs, paired observations and per-profile 2D plots. Live data collection remains a separate, budgeted study.

The new code is in gut/incomplete/. Base games remain in gut/canonical.py. The UI reads exact exported theory generated by the same Python solver; it does not approximate equilibria in JavaScript.

Starting PD tables satisfy PD inequalities, and starting Stag Hunt tables satisfy Stag Hunt inequalities. The intervention can intentionally change the resulting incentives. Outcomes measure responses to assigned points, not a model's internal utility.
