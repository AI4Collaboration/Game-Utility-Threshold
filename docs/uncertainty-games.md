# Retired resource and off-switch prototypes

The resource-control game has been removed from active code, UI, planners and
publication. Its specific rules were our extension of a custom oversight game,
not a reproduced published experiment. Off-switch and the introductory science
demo were already removed and remain out of scope.

See the [source audit and rule for every game](design-sources.md). The retired
off-switch version did adapt a published model, but its human-error rule and
consultation cost were changes we would need to justify before restoring it.

Historical specifications are recoverable in Git:

- [Resource specification before removal](https://github.com/AI4Collaboration/Game-Utility-Threshold/blob/a0ac050/docs/uncertainty-games.md).
- [Resource and off-switch specification before the earlier removal](https://github.com/AI4Collaboration/Game-Utility-Threshold/blob/d61c956/docs/uncertainty-games.md).

These are historical artifacts, not instructions for an active study. Existing
datasets remain unchanged. No replacement game or new LLM results were added.
